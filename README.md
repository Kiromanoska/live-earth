# LIVE EARTH 🌍

Interactive 3D Earth exploration and global data visualization platform.

## Roadmap

- Interactive 3D globe and location search
- Geographic layers and location information
- Satellite orbits and launches
- Weather, maritime and aviation layers (subject to data-source availability)
- Future J.A.R.V.I.S. integration

## Principles

Real data must be clearly distinguished from demonstrations or simulations. No API secrets in frontend code.

Project initialized. Application scaffold coming next.
